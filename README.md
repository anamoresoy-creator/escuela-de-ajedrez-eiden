# Escuela de ajedrez Eiden

Escuela de ajedrez Eiden: aprende a mover las piezas y entrena estrategias, con hojas para imprimir.

- **Aprende a mover**: cómo se mueve cada pieza, con estrellas, obstáculos y capturas.
- **Entrena estrategias**: mate en 1, mate en 2, horquilla, clavada y ensartada, principios de apertura.
- **Hojas para imprimir**: diploma, ejercicios, tablero recortable y guía para familias.

Página estática (un solo `index.html`). Incluye chess.js (BSD-2-Clause) para validar las jugadas.
